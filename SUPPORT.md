# Getting help

Here's where to go, depending on what you need.

- **Docs.** Start with the [README](README.md), then the [docs folder](docs/).
- **Questions and help.** Ask in [GitHub Discussions](https://github.com/security-union/videocall-rs/discussions). Questions about setup, self-hosting or how something works fit best there, and the answers stay searchable for the next person.
- **Chat.** Come say hi on [Discord](https://discord.gg/JP38NRe4CJ).
- **Bugs.** If you've found something that's broken, [open an issue](https://github.com/security-union/videocall-rs/issues/new/choose) using the bug report form. Please search the existing issues first.
- **Feature ideas.** Use the feature request form, or start a Discussion if the idea is still rough.
- **Security vulnerabilities.** Don't open a public issue. Follow [SECURITY.md](SECURITY.md) and report it privately.
